    Quantitative research · personal project · November 2026

    Regime Shift Lab

    When bonds stop protecting a portfolio: testing a rotation between equities, bonds and gold.

    A transparent strategy using four ETFs (SPY, IEF, GLD, SHY), motivated by recent IMF research on weakening equity–bond diversification. It combines momentum, a correlation filter, delayed execution and costs on every buy and sell.

    Over 2022–2026, the simulated annualized return reaches 7.6% versus 6.2% for the 60/40 portfolio. However, the maximum drawdown is larger: −24.0% versus −20.9%. The report also examines periods of underperformance and variants that challenge the value of the filter.

    An integration with TypeSafe AI’s Jev model classifies macroeconomic notes into structured probabilities. This current analysis is kept separate from historical signals; enabling it on the server requires a connection to the provider.

    11 automated tests. Data through November 13, 2026. A retrospective study with no live trading results.

    Fixed income · personal project · November 2026

    Bond Stress Lab

    If interest rates rise by one percentage point, how much loss could a shorter bond portfolio avoid?

    Try the scenario (French) GitHub repository

    The worked example moves €10,000 from a ten-year bond into a two-year bond. Using the European Central Bank’s yield curve for 26 November 2026, the same rate rise produces a simulated loss of €3,829.09 after the transfer, down from €4,454.65. If rates fall, the shorter portfolio also gains less.

    A French-language assistant can run a rate shock and explain which holding drives the result. The scenario file saves the positions and the six dated rates so another analyst can replay it. An independent Python calculation checks the example to the cent.

    Case study · consumer lending · 2026

    Credit Process Intelligence

    Identify where AI delivers a return, how much, and under what conditions.

    Process mining applied to a Dutch bank’s real event log: 13,087 consumer loan applications reconstructed step by step. An approved application spends 99.6% of its processing time waiting, and 51% of approved applications require another round of document collection.

    Three AI opportunities replayed on real applications, assessed financially through Monte Carlo simulation and evaluated against the AI Act and GDPR. Only one is profitable: checking completeness at submission, with a median three-year NPV of +€48k. The abandonment prediction model does not meet its thresholds and is therefore not deployed.

    Includes business analyst deliverables: a scoping brief, AS-IS and TO-BE BPMN models, user stories, an acceptance test plan and change management.

    Case study · public procurement · 2026

    Radar Marchés Publics

    Focus bids on opportunities where you have a better chance of winning.

    A tender discovery tool for SMEs. A warehouse of 1,264,104 awarded contracts (DECP), built with DuckDB and dbt, powers an explainable hybrid ranking of 7,808 open BOAMP notices, using keywords, embeddings, CPV codes and each buyer’s history.

    Since 2024, 25.7% of contracts have received only one bid. SMEs win 59% of contracts but account for 26% of their value. On unseen notices, the hybrid ranking achieves an nDCG@10 of 0.427, ahead of keywords or embeddings alone.

    The same business analysis approach: scoping, personas, BPMN, user stories, a business case, compliance and acceptance testing.

    Open source · 2026 · over 100 stars on GitHub

    JevGrep

    Find code by what it does, without knowing its name.

    Ask a question such as “Where is session expiry handled?” and JevGrep returns the relevant source code snippets, with file paths and line numbers. Use it from the command line, or through an MCP server so a coding agent can explore the repository itself.

    A project started with Nassim Arifette, built on TypeSafe AI’s Jev model. My contribution: adding OpenRouter as a third provider for calling Jev, alongside the TypeSafe API and Vercel AI Gateway.

    # the provider I added
$ jevgrep init --global --provider openrouter

# search for code by its behavior
$ jevgrep search --query "Where is session expiry handled?"

    AI evaluation · hackathon continuation · November 2026

    Gem Lab — Testing AI reliability

    A convincing answer is not always a reliable one. Test the evidence behind it.

    A continuation of the Cloud Run GPU hackathon prototype built with Google ADK, Gemma and Ollama. I reworked it into a small evaluation lab for document-grounded assistants: citing sources, recognizing missing information, resisting prompt injection, choosing current documents, checking arithmetic and following a JSON contract.

    Compare a simple prompt with a more explicit one, inspect each response and export the session as JSON or CSV. The checks are deterministic and limited to these six scenarios; they do not establish general model reliability.

    The hosted demo supports prepared examples and pasted responses. Live Gemma calls are integrated, but provider access is currently unavailable. 16 automated tests cover grading, provenance, API validation and provider failure handling.
