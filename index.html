Open source · 2026 · plus de 100 étoiles sur GitHub

JevGrep

Trouver du code par ce qu’il fait, sans connaître son nom.

On pose une question, par exemple « Où est gérée l’expiration des sessions ? », et JevGrep renvoie les extraits de code source pertinents, avec leurs chemins et numéros de ligne. L’outil s’utilise en ligne de commande, ou via un serveur MCP pour qu’un agent de code explore lui-même le dépôt.

Un projet lancé avec Nassim Arifette sur le modèle Jev de TypeSafe AI. Ma contribution : OpenRouter comme troisième fournisseur pour appeler Jev, aux côtés de l’API TypeSafe et de Vercel AI Gateway.

# le fournisseur que j’ai ajouté
$ jevgrep init --global --provider openrouter

# chercher du code par son comportement
$ jevgrep search --query "Where is session expiry handled?"

StackTypeScript · CLI · MCP · OpenRouter
